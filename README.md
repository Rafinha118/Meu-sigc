
# Sistema Integrado de Gestão Comercial — SIGC

## 📌 Sobre o projeto

O SIGC é um sistema web desenvolvido para auxiliar na gestão de um supermercado, integrando informações de estoque, vendas, produtos, fornecedores e controle financeiro em um único ambiente.

## ⚙️ Como o sistema funciona

O sistema possui três tipos de usuários, cada um com diferentes níveis de acesso:

### 👤 Dono
Responsável pela gestão geral do supermercado. Pode acessar:
- Fluxo de Caixa
- Faturamento
- Modificação de Preços
- Fornecedores
- Adição de Produtos
- Retirada de Produtos

### 👨‍💼 Gerente
Responsável pelo gerenciamento das operações. Pode acessar:
- Gerenciamento de Estoque
- Relatórios de Vendas
- Fornecedores

### 🧑‍💻 Operador de Caixa
Responsável pelas operações de venda. Pode acessar:
- Vendas
- Saída de Estoque
- Produtos e Estoque

## 🔄 Fluxo do sistema

1. O usuário acessa a tela de login.
2. Informa CPF, nome completo e senha.
3. O sistema identifica o tipo de usuário.
4. O usuário é direcionado ao seu painel.
5. Cada usuário acessa somente as funções permitidas para seu cargo.
6. As informações registradas são integradas ao sistema.
7. Vendas, estoque e informações financeiras são atualizados conforme as operações realizadas.

## 🎯 Objetivo

O objetivo do SIGC é centralizar e organizar os processos de gestão comercial, facilitando o controle das operações do supermercado e tornando as informações mais acessíveis e organizadas.
